## 2. Non-Functional Requirements (NFR) Assessment

- **Security & Password Hashing**: Passwords hashed using Argon2id (`argon2-cffi`). Plaintext passwords and hashes are never exposed. Short-lived HS256 JWT access tokens with revocation blacklist.
- **Privacy Enforcement**: Restricted contact details, precise custody locker combinations, and ownership evidence are filtered out by server DTOs before responding to unauthorized callers.
- **Data Integrity & Invariants**: Handover return records are foreign-keyed to approved claims; duplicate claims and duplicate returns are blocked at the service and database levels.
- **Database Portability**: Clean SQLAlchemy 2.x declarative models and Alembic migrations targeting SQLite locally and portable to PostgreSQL without schema refactoring.
- **Audit Logging**: Comprehensive, append-only logs for report moderation, claim decisions, custody transfers, returns, user promotions, and account suspensions.
